# WEBGLOW — Záloha projektu

Tento repozitář obsahuje kompletní zálohu projektu WEBGLOW.

## Obsah

### `/website/`
Kompletní zdrojový kód webu webglow.cz (React 19 + Tailwind CSS 4).

### `/assets/logos/`
- Loga WEBGLOW (ikona W) ve variantách: tmavé, světlé, průhledné pozadí
- Wordmark (W + text WEBGLOW) ve variantách
- Skript pro generování loga (`generate_logo.py`)

### `/assets/instagram/`
- Grafiky pro Instagram příspěvek (1:1) a Reels cover (9:16)
- Before/After obrázky (restaurace, kadeřnictví, fitness)

### `/assets/prospekty/`
- Excel tabulka s potenciálními zákazníky v Praze (barbershopy + restaurace bez webu nebo se zastaralým webem)
- Markdown přehled prospektů
